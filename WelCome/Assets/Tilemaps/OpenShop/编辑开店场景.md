# 编辑开店场景

## 场景与图层

打开 Assets/Scenes/OpenShopScene.unity。场景采用 32×18 格的正交俯视布局，每格 1 个 Unity 单位。

- 地面图块 Tilemaps 下的“草地 Ground”“石板路 Paths”“门前木地板 Shop floor”：地面分层。
- “店铺摆设（可自由移动）”：工坊、摊位、炼金台、陈列台和树木，可在场景视图中移动、复制或删除。
- “顾客路线（移动圆点调整）”：顾客路线。场景视图中的圆点和连线是路点；移动路点即可调整顾客行走范围。
- “顾客（运行预览）”：这里放置的是 Assets/Prefabs/OpenShop/ShopVisitor.prefab 实例。共用外观和移动组件在预制体中调整；每个顾客自己的路线仍由场景路点控制，选中顾客可在 Inspector 调整速度。
- “主控角色（占位）”：玩家角色，带 Rigidbody2D 和碰撞体，可在 Inspector 调整移动速度与活动范围；当前已勾选“反转四向图片”，可按角色素材朝向取消勾选。
- “自定义阻挡区（添加 BoxCollider2D）”：放置额外的隐形阻挡区域。

## 带外景的商店示范布局

`Assets/Scenes/OpenShopScene_MapDemo.unity` 是独立的 40×26 格商店示范场景，原始 `OpenShopScene.unity` 保留原布局。商店位于画面中后部，室内铺木地板，后侧和两边有石砖墙；正面留出四格宽的入口。门前连接宽石板街，两侧用树木、花盆和花草补出街景。

室内两侧各有 6 个展示架占位，后方 U 形柜台由现有摊位和展示架素材组合；玩家出生在柜台内，可走到店内门槛附近，但活动范围限制在室内。6 位顾客使用独立的行为档案：有人只在街上路过，有人经过时会看一眼店铺并可能进店，店内顾客会在可达的陈列架、柜台、随机闲逛点和出口之间选择。熟人档案可以触发招呼，附近暂停的顾客也可能聊一会儿。展示架目前是带碰撞体的场景摆设，供后续接入陈列和选购玩法；石砖墙后续可以替换成专用墙体素材。

## 顾客行为和配表调整

顾客行为参数放在仓库根目录 `_ConfigExcels/Datas/`：

- `shop_behavior.xlsx`：全局的注意范围、驻足时间、门口/货架思考气泡概率、商品不合偏好时显示低落表情的概率与时长、商品陈列对进店意愿的加成，以及社交距离、聊天时长和冷却。
- `shop_npc_profile.xlsx`：每种人物档案的路过注意率、进店倾向、好奇心、健谈程度、赶路程度、偏好商品类别、社交组、店内目标权重、移动速度和停留时间。示范场景按顺序给 6 位顾客分配档案 ID 1001–1006。

修改表格后，双击 `_ConfigExcels/导出街区顾客配置.bat`，生成的 JSON 会写入 `WelCome/Assets/Resources/Luban/Output/Json/`。等 Unity 导入完成后再进入 Play 模式。概率类字段填 0–100；浏览、柜台、离店、闲逛是相对权重，会只在当前可达的目标之间抽选，不要求权重合计 100。熟人招呼依据相同的 `social_group_id`；`door_keepout_radius` 会让聊天点避开门口和柜台。

`preferred_need_tag` 使用商品需求标签（1 照明、2 保温、3 清洁、4 省力、5 奢侈、6 农用）；填 0 表示不设偏好。顾客在货架前出现思考气泡并停留结束后，若看到的商品类别与偏好不同，才可能按全局概率显示低落表情。

## 资源路径与引用方式

Unity 工程根目录是 WelCome/；下表中的 Assets/... 均为相对于该目录的 Unity 资产路径。

| 资产路径 | 用途 | 引用方式 |
| --- | --- | --- |
| Assets/Art/OpenShop | 开店场景的角色、摆设和地面图片 | 场景生成器通过 AssetDatabase 读取；生成场景和预制体保存直接引用 |
| Assets/Tilemaps/OpenShop/Tiles | 草地、石板路和木地板 Tile 资产 | Tilemap 场景对象直接引用 |
| Assets/Prefabs/OpenShop/ShopVisitor.prefab | 场景游逛顾客预制体 | OpenShopScene 中的预制体实例直接引用 |
| Assets/Resources/Characters | 雀、莱亚的立绘 | UIHelper 通过 Resources.Load 按路径加载 |
| Assets/Resources/Luban/Output/Json | Luban 配置 JSON | ConfigManager 通过 Resources.Load 按路径加载 |

Resources/ 专用于代码按字符串动态查找的运行时资源；场景、Tilemap 和预制体能直接引用的资产放在普通 Assets 子目录。当前未使用 Addressables 或自定义 AssetBundle 加载。ResourceSystem.cs 管的是金币、魔力和材料等游戏内数值，不负责加载文件。

## 操作主控角色

进入 Play 模式后使用 **WASD** 或 **方向键** 移动，按住 **Shift** 奔跑；滚动鼠标滚轮可缩放镜头。当前占位角色由脚本直接切换四方向的两帧图片，因此没有 Animator 状态机；方向按 `player_down/left/right/up_0/1.png` 文件名对应，默认关闭“反转四向图片”。正式接入雀或莱亚时可替换这些帧；只有新素材朝向与文件名相反时，才需要开启反转选项。

相机会平滑跟随主控角色并向门外略微取景，让玩家在室内活动时也能看到门前街景。

## 编辑阻挡物和行走范围

- 每件店铺摆设自带 BoxCollider2D。选中摆设，在 Inspector 调整碰撞体的 Size/Offset，或用 Edit Collider 手柄让碰撞区域贴合实际底座；移除碰撞体后，主控角色即可穿过该摆设。
- 需要额外挡路时，在“自定义阻挡区（添加 BoxCollider2D）”下创建空物体并添加 BoxCollider2D，确认 `Is Trigger` 未勾选；移动物体并调整碰撞体的 Size/Offset 来圈出墙、柜台边缘等不可通过区域。
- 主控角色的 `minBounds` / `maxBounds` 决定矩形活动范围。示范场景将范围限制在室内门槛后方，因此玩家不能走到室外；顾客有独立寻路范围。选中角色后可在 Inspector 修改坐标，蓝色线框会显示玩家范围。地面 Tilemap 目前只负责显示地面，不自动阻挡移动；若要做不规则区域，可用多个 BoxCollider2D 拼出边界。
- 顾客按约 0.5 米的网格寻路，随机选择的路点只作为闲逛目标，不再按固定路线循环。寻路会避开带碰撞体的摆设；若摆设改变后顾客走不通，确认阻挡体和寻路范围，再调整顾客路线里的候选路点。

## 用 Tile Palette 编辑地面

想先看完整布局，可点击“代号开店 > 打开绘制示范地图”，打开 `OpenShopScene_MapDemo.unity`。

在示范地图或原场景中绘制：

1. 点击“代号开店 > 准备地图绘制”，打开 Tile Palette。室内示范图会选中“室内木地板 Shop floor”；原场景会选中“草地 Ground”。
2. 在 Palette 里点选瓦片，再到 Scene 视图按住鼠标左键拖动。
3. 室内示范图铺地面时选 `Wood_Floor` 和“室内木地板 Shop floor”；改店铺墙体或门前街道时选 `Cobble_Path` 和“店铺边界与外部石路 Paths”。原场景也可以选“石板路 Paths”或“门前木地板 Shop floor”。

素材 PNG 位于 Assets/Art/OpenShop，为 32 PPU、点采样像素图。当前顾客和摆设图用于搭场景与预览动线；替换素材时尽量保留原有尺寸，避免场景比例变化。

菜单“代号开店 > 生成或重建开店场景”可重新生成初始布局。确认重建会覆盖该场景内的手动摆放；开始自行编辑后，无需再次重建。
